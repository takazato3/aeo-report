# SNS/note転用ルール

## 絶対原則

- 自動投稿・自動送信は一切しない。生成物は必ずドラフトとして
  リポジトリ内に保存し、投稿は人間が行う
- Xは匿名persona「Ops Octopus（タコ）」。個人・実名・本業を
  推測させる要素を含めない
- LinkedInは本パイプラインの対象外（実名側のため生成しない）

## X投稿の文体（タコpersona）

- クールな観察者。「これ、面白くない？」程度の温度。
  焦り・危機感・煽りは出さない
- 一人称は基本なし、「タコ的には」可。強い感情時のみ「俺」
- データ・事実を先に、最後にタコ視点の一言
- 140字以内（ハッシュタグ含む）。#AEO #AI検索 を末尾に
- 🐙絵文字はスパリング（毎回は使わない）
- URLは本文に入れない（リプライ欄想定。ドラフトには
  別行でURLを記載）

## note記事のトーン

- ブログの転載ではなく「AIドリブンマーケの実験・観察記」
  として書き直す（自サイトとの内容重複を避ける）
- 運営者個人は特定させない。「Ops Octopusの中の人」視点
- 1500〜2500字。末尾にapp.ops-octopus.comへの導線1つ
