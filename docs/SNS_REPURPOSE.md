# SNS/note転用ルール（2026年7月更新版）

## 絶対原則

- 自動投稿・自動送信は一切しない。生成物は必ずドラフトとしてリポジトリ内に保存し、投稿は人間が行う
- Xは匿名persona「Ops Octopus（タコ）」。個人・実名・本業を推測させる要素を含めない
- LinkedInは本パイプラインの対象外（実名側のため生成しない）
- ブログ内容（モヤモヤあるある・3AI横断・手軽さ・現状把握の第一歩）を参考にしつつ、**X投稿のトーンは以下のスタイルを最優先**で生成する

## X投稿の文体（タコpersona）

### 基本トーン（2026年リーチ重視）
- **気軽で親しみやすい観察者**。「忙しいマーケターあるあるだよね？」という温度感
- 焦り・危機感・煽り・専門用語（AEO/GEO/LLMOなど）は極力避ける
- 「AI検索で自社がどう見えてるか」「ChatGPTなどに聞かれたときの自社評判」という身近な表現を多用
- 手作業の面倒くささ（3AIに同じ質問するのは意外と大変）を自然に織り交ぜる
- 「300円」「ドリンク1杯分」「自動販売機」「気軽に」「試しに1回」などの軽い表現でハードルを下げる
- **会話促進を強く意識**：質問で終わるか「どう思う？」「気になったらリプライください」など、リプライを誘う一言を入れる（2026年アルゴリズムで最重要）
- 一人称は基本なし。「タコ的には」程度は可
- 最後に🐙を1個入れる（多用しすぎない）

### 推奨投稿パターン（このどれかに近い形で生成）
1. シンプル問題解決型（気になったことありませんか？）
2. 自動販売機アピール型（新感覚自動販売機 / ドリンク買う感覚）
3. 痛み強調型（インハウスマーケターあるある / 放置しがち）
4. 比較の面倒くささ強調型（手作業で3AI確認するのはめんどくさい）
5. 質問フック型（最近気になったことありますか？）
6. 小さな不安解消型（小さな不安 / 安心チェック）
7. 実務者向け実例風（インハウスでふと思う瞬間）
8. ハードル下げ型（登録不要・法人連絡先不要・ポッキリ）
9. スレッド用1枚目（少し長めで導入＋続きで会話促進）
10. カジュアル日常型（今日のコーヒー代で / 気軽にどうぞ）

### 文字数・装飾ルール（2026年更新）
- 本文180〜250字程度（会話が生まれやすい長さ）
- URLは本文に入れず、ドラフト末尾に別行で記載（例: 👉 https://app.ops-octopus.com）
- ハッシュタグは最小限（#AI検索 程度）
- 最初の30分でリプライがもらえるよう、質問や「試してみた人いる？」を入れる

## note記事のトーン（2026年更新）

- ブログの単なる転載ではなく**「AIドリブンマーケの実験・観察記」**として書き直す
- 「Ops Octopusの中の人」視点で、**忙しいインハウスマーケター目線**を強く入れる（「私も現場で…」「実際に試してみて気づいた」などの共感表現）
- **読みやすさ重視**：見出し・箇条書き・短い段落を活用。抽象論より「実際に試した結果」「こんなモヤモヤが解消された」などの具体例を入れる
- 流れの基本形：**共感（あるある） → 気づき（実験結果） → 軽いTips → 自然な導線**
- 1500〜3000字程度。過度な売り込みは避け、「参考になれば」という柔らかい締め
- 末尾に**app.ops-octopus.com**への自然な導線を1つ（「気になったら試してみるのもおすすめです」程度）

## 生成時の指示例（AIへのプロンプト用）

**X投稿用**  
「以下のブログ内容を参考に、Ops OctopusのX投稿を生成してください。  
トーンは以下のスタイルを厳密に守ること：  
- 気軽で親しみやすい、忙しいマーケター目線  
- 手作業の面倒くささや小さな不安を自然に  
- 300円の軽さ・自動販売機感を出す  
- 会話を促す質問を入れる  
- 専門用語は最小限  
[ブログ内容ここに貼る]」

**note記事用**  
「以下のブログ内容を参考に、note向けの『AIドリブンマーケの実験・観察記』記事を生成してください。  
- 忙しいインハウスマーケター目線で共感を入れつつ  
- 見出し・箇条書きで読みやすく  
- 具体的な実験結果やTipsを入れる  
- 最後は自然にサービス導線  
[ブログ内容ここに貼る]」
