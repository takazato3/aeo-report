# キーワードマップ

日本のB2Bマーケター・事業会社のマーケ担当者が検索しそうな AEO/LLMO/GEO 関連クエリの棚卸し。
ブログ初期コンテンツ（15本）の選定と、週次の判断ロジック（`docs/CONTENT_AUTOPILOT.md`）における
「クエリギャップ→新規記事生成」判断の初期母集団として使う。

## 使い方

- **優先度 P1**：初期15本に含める記事。当初はちょうど15本。以降、週次サイクルで
  P2から昇格した記事も随時P1として追加されていく（昇格日を併記）。
- **優先度 P2**：初期リリース時点では書かない。週次のGSC/GA4分析（インプレッション・掲載順位の実績）
  を見て、新規生成またはリライトを判断する候補プール。
- **済**：既に対応記事が存在するクエリ。新規記事のカウントには含めない。
- 各クラスタの記事タイトル案は仮題。実際の執筆時にGSC実データやCTRを見て微調整してよい。

## 競合ギャップの考え方

Profound・Peec AI（海外勢）は英語圏・グローバル企業向けの高機能計測ツール訴求が中心で、日本語ロングテールの
実務クエリ（設定方法・書き方・自社が出てこない時の対処など）はほぼ手つかず。LLMOコンパス等の国内勢は
用語解説・概念系コンテンツは押さえているが、「独自スコアではなく生の回答をそのまま見せる」という透明性の
訴求や、実務担当者が一人で試せる具体的な手順系コンテンツは薄い。このギャップ（日本語・ロングテール・実務・
非ブラックボックス）を初期コンテンツの優先領域とする。
